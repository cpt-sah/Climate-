# AI & Environment — reference draft

Open index.html in a browser. Edit index.html for content and styles.css for appearance. Keep the assets folder beside them. Google Fonts requires an internet connection; local fallback fonts remain usable offline.

Mobile below 600px: compact header, navigation on a second line, a tall feature area, then one stacked column of cards. The sketch's hamburger was replaced with visible controls so the navigation stays discoverable without JavaScript.

## Assignment features in the draft

- HTML and CSS only, no framework or JavaScript.
- Sticky header, Flexbox layouts, mobile breakpoint below 600px, footer and Google Fonts.
- Six sourced factual statements, two per card, plus context distinguishing all data centers from AI.
- Nine distinct pseudo selectors: :root, :hover, :focus-visible, :active, :first-child, :last-child, ::before, ::after and ::selection.
- Keyboard focus styles, descriptive image text, skip link, semantic headings and reduced-motion support.
- Top navigation buttons intentionally do not navigate, following the assignment. Article and source links work.
